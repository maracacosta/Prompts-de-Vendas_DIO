# 🧠 Análise de Relatórios de Vendas com IA

## 📌 Descrição do Projeto
Projeto desenvolvido como parte do desafio da DIO, com foco em análise de dados de vendas utilizando ferramentas de Inteligência Artificial e prompts bem estruturados.

## 🎯 Objetivos
- Aplicar conceitos de IA para interpretar relatórios;
- Gerar insights para a tomada de decisão;
- Documentar e versionar tecnicamente no GitHub.

## 🗂️ Estrutura do Repositório
- `data/`: Planilhas utilizadas no projeto;
- `prompts/`: Prompts aplicados com exemplos;
- `insights/`: Relatórios com conclusões e aprendizados;
- `imagens/`: Gráficos e prints dos resultados.

## 🧪 Ferramentas Utilizadas
- IA generativa (ex: ChatGPT, Copilot, Gemini);
- Excel / Google Sheets;
- GitHub.
